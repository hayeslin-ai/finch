# Subsystem rules

按服务、领域、应用或路由区拆分特殊约定。只写差异，不重复根目录规则。

建议文件名：`docs/subsystems/<module-or-route-area>.md`。

Finch 当前子系统：

- `agent/`：模型会话、系统提示与工具注册。
- `remote/`：堡垒机登录、远程协议、查询计划授权与执行。
- `security/`：脱敏规则与执行边界。
- `repository/`、`logs/`：本地源码与日志读取。
- `knowledge/`、`storage/`：故障经验与会话落盘。
- `config/`、`cli/`、`app/`：配置、命令入口与唯一组装根。
- `ports/`：核心依赖的扩展端口。

每份文件必须包含：

- 责任边界：该模块负责什么、不负责什么。
- 入口与出口：对外契约、事件、缓存或存储边界。
- 局部禁区：不能绕过的模块内约束。
- 验证命令：只跑该模块的最短命令。
